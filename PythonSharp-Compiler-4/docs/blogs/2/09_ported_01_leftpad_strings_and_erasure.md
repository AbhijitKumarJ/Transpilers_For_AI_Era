## 1. The Target: Why `left-pad`?

In 2016, a simple 11-line npm package called `left-pad` broke the internet when it was temporarily unpublished. Despite its simplicity, padding strings to fixed column widths is a foundational utility used in CLI tables, financial reports, fixed-width file formats, and numeral alignment.

Porting `left-pad` is the ideal "Hello World" for a transpiler because it exercises:
- Basic primitive types (`string`, `int`, `char`).
- Default function parameters (`string ch = " "`).
- Property access mapping (`str.Length` $\to$ `len(str)`).
- Slicing methods (`str.Substring(start, len)` $\to$ `str[start:start+len]`).
- Integer division semantics (`total / 2`).

## 3. The C# Source Implementation: `PadUtil.ps`

The utility is implemented in namespace `TextUtil` in [`PadUtil.ps`](file:///home/abhijit/Videos/transpilers/PythonSharp/Samples/Ported/01_leftpad/PadUtil.ps):

```csharp
namespace TextUtil;

using PythonSharp.Core;

public class PadUtil
{
    public static string LeftPad(string str, int length, string ch = " ")
    {
        if (str.Length >= length)
        {
            return str;
        }

        int targetPad = length - str.Length;
        string padStr = "";
        while (padStr.Length < targetPad)
        {
            padStr = padStr + ch;
        }

        if (padStr.Length > targetPad)
        {
            padStr = padStr.Substring(0, targetPad);
        }

        return padStr + str;
    }

    public static string RightPad(string str, int length, string ch = " ")
    {
        if (str.Length >= length)
        {
            return str;
        }

        int targetPad = length - str.Length;
        string padStr = "";
        while (padStr.Length < targetPad)
        {
            padStr = padStr + ch;
        }

        if (padStr.Length > targetPad)
        {
            padStr = padStr.Substring(0, targetPad);
        }

        return str + padStr;
    }

    public static string Center(string str, int length, string ch = " ")
    {
        if (str.Length >= length)
        {
            return str;
        }

        int totalPad = length - str.Length;
        int leftLen = totalPad / 2;
        int rightLen = totalPad - leftLen;
        string leftStr = LeftPad("", leftLen, ch);
        string rightStr = RightPad("", rightLen, ch);
        return leftStr + str + rightStr;
    }
}
```

Notice how clean and idiomatic the C# code is. It provides `LeftPad`, `RightPad`, and `Center` algorithms with default parameters and guard clauses.

## 4. The Transpiled Output: Zero-Cost Type Erasure

Compiling the project with:
```bash
psc build Samples/Ported/01_leftpad -o Samples/Ported/01_leftpad/dist
```
produces [`Samples/Ported/01_leftpad/dist/text_util.py`](file:///home/abhijit/Videos/transpilers/PythonSharp/Samples/Ported/01_leftpad/dist/text_util.py):

```python
# Auto-generated by PythonSharp (psc) — Bytecode line-pinned to PadUtil.ps
from __future__ import annotations

class PadUtil:
    __ps_types__ = ('TextUtil.PadUtil',)
    __slots__ = ()

    @staticmethod
    def left_pad(str: str, length: int, ch: str = ' ') -> str:
        if len(str) >= length:
            return str
        target_pad: int = length - len(str)
        pad_str: str = ''
        while len(pad_str) < target_pad:
            pad_str = pad_str + ch
        if len(pad_str) > target_pad:
            pad_str = pad_str[0:0 + target_pad]
        return pad_str + str

    @staticmethod
    def right_pad(str: str, length: int, ch: str = ' ') -> str:
        if len(str) >= length:
            return str
        target_pad: int = length - len(str)
        pad_str: str = ''
        while len(pad_str) < target_pad:
            pad_str = pad_str + ch
        if len(pad_str) > target_pad:
            pad_str = pad_str[0:0 + target_pad]
        return str + pad_str

    @staticmethod
    def center(str: str, length: int, ch: str = ' ') -> str:
        if len(str) >= length:
            return str
        total_pad: int = length - len(str)
        left_len: int = total_pad // 2
        right_len: int = total_pad - left_len
        left_str: str = PadUtil.left_pad('', left_len, ch)
        right_str: str = PadUtil.right_pad('', right_len, ch)
        return left_str + str + right_str
```

### Architectural Breakdown of the Output:
1. **Namespace to Module**: `namespace TextUtil;` automatically maps to `text_util.py`.
2. **Identifier Normalization**: `PadUtil.LeftPad` maps to `PadUtil.left_pad` via `pascal_to_snake()`.
3. **Zero-Wrapper String Erasure**: `str.Length` compiles straight to `len(str)`. There is no `StringWrapper` class.
4. **Substring Lowering**: `padStr.Substring(0, targetPad)` lowers directly to native slice syntax `pad_str[0:0 + target_pad]`.
5. **Integer Division**: C# `int / int` performs integer division. Python's `/` operator returns a float. PythonSharp automatically lowers integer division to Python's `//` operator (`total_pad // 2`).
6. **Class Optimization**: `__slots__ = ()` ensures zero dictionary allocation overhead.

## Key Takeaways
