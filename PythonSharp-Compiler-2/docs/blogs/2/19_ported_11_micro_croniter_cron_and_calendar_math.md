## 1. The Specification: 5-Field Standard Cron

Standard Unix cron expressions consist of five space-separated fields:

```
┌───────────── minute (0 - 59)
│ ┌───────────── hour (0 - 23)
│ │ ┌───────────── day of the month (1 - 31)
│ │ │ ┌───────────── month (1 - 12)
│ │ │ │ ┌───────────── day of the week (0 - 6) (Sunday to Saturday)
│ │ │ │ │
* * * * *
```

Examples:
- `*/15 * * * *`: Every 15 minutes.
- `30 8 * * *`: Daily at 08:30 AM.
- `0 9 * * 1-5`: Weekdays (Mon–Fri) at 09:00 AM.
- `0 0 29 2 *`: Leap years only, midnight on February 29th.

## 3. The C# Source Implementation: `Croniter.ps`

In [`Croniter.ps`](file:///home/abhijit/Videos/transpilers/PythonSharp/Samples/Ported/11_micro_croniter/Croniter.ps), calendar math is encapsulated in `CronCalendar`:

### 1. Leap Year & Days in Month
```csharp
public static bool IsLeapYear(int year)
{
    if (year % 400 == 0) return true;
    if (year % 100 == 0) return false;
    return year % 4 == 0;
}

public static int DaysInMonth(int year, int month)
{
    if (month == 2)
    {
        return IsLeapYear(year) ? 29 : 28;
    }
    if (month == 4 || month == 6 || month == 9 || month == 11)
    {
        return 30;
    }
    return 31;
}
```

### 2. Sakamoto's Day-of-Week Algorithm
Computing the day of week ($0 = \text{Sunday}, 6 = \text{Saturday}$) without calling external C library functions:

```csharp
public static int GetDayOfWeek(int y, int m, int d)
{
    List<int> t = new List<int>();
    t.Add(0); t.Add(3); t.Add(2); t.Add(5); t.Add(0); t.Add(3);
    t.Add(5); t.Add(1); t.Add(4); t.Add(6); t.Add(2); t.Add(4);
    int adjY = m < 3 ? y - 1 : y;
    return (adjY + adjY / 4 - adjY / 100 + adjY / 400 + t[m - 1] + d) % 7;
}
```

### 3. Chronological Stepping: `AddMinute`
```csharp
public static CronDateTime AddMinute(CronDateTime dt)
{
    int y = dt.Year;
    int m = dt.Month;
    int d = dt.Day;
    int h = dt.Hour;
    int min = dt.Minute + 1;

    if (min >= 60)
    {
        min = 0;
        h += 1;
        if (h >= 24)
        {
            h = 0;
            d += 1;
            int maxDays = DaysInMonth(y, m);
            if (d > maxDays)
            {
                d = 1;
                m += 1;
                if (m > 12)
                {
                    m = 1;
                    y += 1;
                }
            }
        }
    }

    return new CronDateTime(y, m, d, h, min);
}
```

# 3. Weekday skip: 0 9 * * 1-5 (Skipping Saturday & Sunday)

# 4. Leap Year Rollover: 0 0 29 2 *
it_leap = CronIterator("0 0 29 2 *", CronDateTime(2026, 1, 1, 0, 0))
assert it_leap.get_next().to_iso_string() == "2028-02-29 00:00"        # 2028 is leap!
