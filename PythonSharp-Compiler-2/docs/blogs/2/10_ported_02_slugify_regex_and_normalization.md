## 1. The Target: URL Slug Generation

A **slug** is the human-readable, URL-friendly portion of a web address. For example:
- Input: `"Hello World!"` $\to$ Output: `"hello-world"`
- Input: `"  Special @#$ Characters & More  "` $\to$ Output: `"special-characters-more"`
- Input: `"C# to Python Transpiler 2026"` $\to$ Output: `"c-to-python-transpiler-2026"`

To produce clean slugs, an algorithm must:
1. Strip leading and trailing whitespace and punctuation.
2. Replace contiguous runs of non-alphanumeric characters with a single separator (`-` or `_`).
3. Support optional case folding (lowercasing).
4. Never leave trailing separators at the end of the slug.

## 3. The C# Source Implementation: `Slugifier.ps`

The algorithm is implemented in [`Slugifier.ps`](file:///home/abhijit/Videos/transpilers/PythonSharp/Samples/Ported/02_slugify/Slugifier.ps):

```csharp
namespace SlugifyUtil;

using PythonSharp.Core;

public class Slugifier
{
    public static string Slugify(string text, string separator = "-", bool lowercase = true)
    {
        if (text.Length == 0)
        {
            return "";
        }

        string normalized = lowercase ? text.ToLower() : text;
        string result = "";
        bool prevWasSep = false;

        int i = 0;
        while (i < normalized.Length)
        {
            string ch = normalized[i];
            bool isAlphaNum = IsAlphanumeric(ch);

            if (isAlphaNum)
            {
                result = result + ch;
                prevWasSep = false;
            }
            else if (!prevWasSep && result.Length > 0)
            {
                result = result + separator;
                prevWasSep = true;
            }

            i += 1;
        }

        while (result.EndsWith(separator))
        {
            result = result.Substring(0, result.Length - separator.Length);
        }

        return result;
    }

    private static bool IsAlphanumeric(string ch)
    {
        if (ch >= "a" && ch <= "z")
        {
            return true;
        }
        if (ch >= "A" && ch <= "Z")
        {
            return true;
        }
        if (ch >= "0" && ch <= "9")
        {
            return true;
        }
        return false;
    }
}
```

### Compiler Features Exercised:
1. **Ternary Operator**: `string normalized = lowercase ? text.ToLower() : text;`
2. **String Indexer**: `string ch = normalized[i];` accessing individual character strings.
3. **Compound Assignment**: `i += 1;`
4. **Standard Library String Methods**: `.ToLower()`, `.EndsWith()`, and `.Substring()`.

```python
from __future__ import annotations

class Slugifier:
    __ps_types__ = ('SlugifyUtil.Slugifier',)
    __slots__ = ()

    @staticmethod
    def slugify(text: str, separator: str = '-', lowercase: bool = True) -> str:
        if len(text) == 0:
            return ''
        normalized: str = text.lower() if lowercase else text
        result: str = ''
        prev_was_sep: bool = False
        i: int = 0
        while i < len(normalized):
            ch: str = normalized[i]
            is_alpha_num: bool = Slugifier.is_alphanumeric(ch)
            if is_alpha_num:
                result = result + ch
                prev_was_sep = False
            elif not prev_was_sep and len(result) > 0:
                result = result + separator
                prev_was_sep = True
            i += 1
        while result.endswith(separator):
            result = result[0:0 + (len(result) - len(separator))]
        return result

    @staticmethod
    def is_alphanumeric(ch: str) -> bool:
        if ch >= 'a' and ch <= 'z':
            return True
        if ch >= 'A' and ch <= 'Z':
            return True
        if ch >= '0' and ch <= '9':
            return True
        return False
```

### Key Codegen Transformations:
- **Ternary Lowering**: The C# ternary `lowercase ? text.ToLower() : text` is lowered to Python's native conditional expression `text.lower() if lowercase else text`.
- **Method Erasure**: `text.ToLower()` maps to `text.lower()`, and `result.EndsWith(sep)` maps to `result.endswith(sep)`.
- **Private Encapsulation**: `IsAlphanumeric` is marked `private` in C#. The compiler allows calls from `Slugify` because both reside within the same enclosing `TypeSymbol`, and emits `Slugifier.is_alphanumeric(ch)`.
